## 1차 심사 기준 (배점 비공개)

1. **차량특화성** — 모바일 대비 차량에서만의 가치, 주행/정차 맥락·차량 기능과 결합
2. **창의성** — 독창성, Pain Point & Needs 정의와 해결 방식
3. **기술 활용성** — Pleos SDK·API를 *핵심 기능*에 활용
4. **사업성** — 타깃, 예상 MAU, Retention, 확대 계획
5. **[가산점]** 시연 영상(목업·화면녹화 인정) → GitHub(소스+APK) 단계별 가산

## 제출물

- 필수: 접수양식(기획서) + 전원 서명 동의서. 팀이면 팀원 전원 CC
- 선택: 시연 영상, GitHub 저장소(`apk/팀명_앱이름_release.apk`, release 빌드), 숏폼 링크
- README 필수 내용: 앱 이름·한 줄 소개, 실행 방법, 테스트 환경·설정, APK 위치
- Private repo 가능 → 심사용 계정 Collaborator 초대 (쓰기 권한도 부여됨 주의)
- 수정 제출: `[수정제출] ...` 제목, 전체 자료 + 동의서 재첨부, 마지막 제출본 심사

## 개발 환경 (Pleos Connect SDK)

| 모듈 | 용도 |
|---|---|
| Vehicle SDK | 차량 상태 조회·제어 (속도, 도어, 공조, 시트, 에너지, ADAS 상태, 와이퍼 등) |
| FusedLocation SDK | 차량 위치 |
| NaviHelper SDK | 경로 안내 제어·내비 정보 |
| TextToSpeech / SpeechToText SDK | 음성 입출력 |

- minSdk **28 이상**, Gradle 8.0+, Java/Kotlin, JDK 17
- 에뮬레이터: Pleos Connect v2.1.0 (API 34, Automotive). Mac(arm64) 이미지 URL:
  `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-arm64-sys-img.xml`
- Maven: `https://nexus-playground.pleos.ai/repository/maven-releases/`
- 의존성: `ai.pleos.playground:Vehicle:2.3.2`
- 권한은 `pleos.car.permission.*` Manifest 선언 (런타임 팝업 아님). **실제 쓰는 최소 권한만**
- 지원 여부는 `checkXXXCapabilities`로 먼저 확인 → 에뮬레이터/차종마다 다름
