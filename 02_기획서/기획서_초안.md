**앱명 / 프로젝트명:** JARI (자리) — 몸 상태를 말하면 자리를 맞춰주는 차량 AI 에이전트

## 1. 앱 한 줄 소개

"허리가 아파", "너무 졸려"처럼 **기능이 아니라 몸 상태를 말하면** 시트·창문·공조 시트를 알아서 조합해 주고,
말하지 않아도 **2시간째 운전 중이면 먼저 자세를 바꿔 주는** 탑승자 컨디션 케어 에이전트.

## 2. 기획 배경

**불편한 순간 ① 장거리 운전 — 피로는 쌓이는데 자세는 그대로**
- 2026년 상반기 고속도로 교통사고 사망자 95명 중 68명(71.6%)이 졸음운전·주시태만이 원인이었다(한국도로공사). 문제의 배경으로 인용한 것이며, JARI가 사고를 줄인다는 근거는 없다.
- 도로공사는 "2시간 운전 시 15분 휴식"을 권고하지만, 운전자는 자신이 몇 시간째 같은 자세인지 의식하지 못한다.
- 시트에는 허리 지지대·통풍·열선이 이미 달려 있지만, 주행 중 화면 메뉴를 찾아 들어가 조작하는 것은 그 자체가 주의 분산이다.

**불편한 순간 ② 동승자 — 내 자리를 내가 못 바꾼다**
- 뒷좌석의 아이·부모님은 시트와 창문을 스스로 조절하기 어렵고, 결국 운전자가 주행 중에 대신 조작한다.

**불편한 순간 ③ 전기차 충전 — 30분을 불편한 운전 자세로 버틴다**
- 국내 전기차는 109만 5천 대(2026년 6월, 국토교통부)이고, 급속충전은 평균 38분이 걸린다(대한교통학회지 2023, KPX 자료 인용).
- 충전하는 동안 운전자는 운전 자세 그대로 스마트폰을 보며 기다린다.

**이미 있는 해결책과 남는 빈틈** (과장 없이)
- 차량 음성비서 Gleo AI는 창문·공조·시트·트렁크를 음성으로 제어하고, "너무 더운데?" 같은 돌려 말하기도 처리한다(현대차그룹 공식 자료). "말로 시트를 조절한다"는 것만으로는 차별점이 아니다.
- 에르고 모션 시트 장착 차량(그랜저 등)에는 주행 1시간 뒤 자동으로 작동하는 '스마트 자세 보조'가 이미 있다. 이 차량에서 JARI의 "먼저 챙기기"는 중복이다.
- 남는 빈틈(가설): ① 에르고 모션 시트가 없는 차종·트림에는 장거리 주행 중 자세를 바꿔 주는 자동 기능이 없다 **[확인: 아반떼(CN8) 트림별 시트 사양]**
  ② 증상 → 여러 장치 조합, 주행 중 위험한 요청의 안전한 대안, 충전 중 휴식을 하나의 흐름으로 묶은 기능은 순정 자료에서 확인되지 않는다 **[확인: Gleo AI의 시트 위치·통풍 제어 범위는 공개 자료로 확인 못 함]**

## 3. 앱 주요 기능 및 차량 특화 요소

| 기능 | 해결하는 문제 | 사용하는 차량 신호 / SDK |
|---|---|---|
| 증상 기반 자세 조합 — "허리가 아파" → 허리 지지대↑ + 열선 2단, "추워" → 열선 + 열린 창문 닫기 | 기능 이름을 몰라도 됨, 주행 중 메뉴 탐색 불필요 | STT → Vehicle(Seat 위치·열선·통풍, Window) → TTS |
| 복합 문장 — "조수석 눕히고 열선 켜줘" | 한 번에 여러 조작 | 동일 |
| 먼저 챙기기 — 연속 운전 2시간마다 허리 지지대 위치를 바꾸고 휴식 권유 (에르고 모션 시트가 없는 트림 대상. 피로·통증 개선 효과는 검증하지 않았음) | 같은 자세로 오래 운전하는 상황 | Vehicle(Gear: 주행 시간 측정, Seat 허리 지지) + TTS |
| 주행 안전 가드 — 기어가 P가 아니면 운전석 자세 큰 변경·트렁크 열기 차단, "졸려"에는 눕히는 대신 창문 20% + 통풍 3단 + 휴게소 안내 | 위험한 명령을 안전한 대안으로 바꿈 | Vehicle(Gear) |
| 충전 중 휴식 — 충전이 시작되면 휴식 자세, 끝나면 운전 자세로 자동 복귀 | 충전 대기 시간의 불편 | Vehicle(EvBattery 충전 상태·SoC, Seat) |
| 충전소 안내 — 배터리 20% 이하면 먼저 알리고, "충전소 찾아줘" → 빈 충전기 중 최단거리로 길안내 | 충전 불안 | Vehicle(EvBattery SoC) + NaviHelper(requestRoute) |
| 탑승 좌석만 조절 — "모두 따뜻하게" → 사람이 앉은 좌석만 | 빈 좌석 낭비 방지 | Vehicle(Seat 점유 센서) |
| 트렁크·프렁크·충전구 음성 개폐 | 짐을 든 채 조작 | Vehicle(Door, EvBattery 충전구) |

**왜 폰이 아니라 차여야 하는가**
- 핵심 동작이 전부 차량 액추에이터(시트 모터·창문·도어)이고, 판단 근거가 전부 차량 신호(기어·점유 센서·충전 상태·배터리)다. 폰에서는 둘 다 접근할 수 없다.
- 주행/정차에 따라 **같은 말에 다르게 답한다.** "졸려"는 정차 중이면 휴식 자세, 주행 중이면 환기 + 휴게소 안내다.

## 4. 주요 사용 시나리오

**페르소나:** 주말마다 부모님을 모시고 장거리를 다니는 30대 아반떼 운전자
> 5·6번(충전)은 Pleos Connect 탑재 전기차가 국내에 출시된 뒤에 해당하는 장면이다. 현재 확인된 국내 탑재 차종(그랜저·아반떼)에서는 1~4번과 7번이 대상이다.

1. **출발 전(정차)** — 뒷좌석 어머니가 "뒷좌석 좀 눕혀줘" → 뒷좌석 등받이 조절. 운전자는 "운전 자세" 한마디로 자세 복귀.
2. **주행 1시간** — "허리가 아파" → 허리 지지대를 높이고 열선 2단. 화면을 보지 않고 음성으로만 끝난다(주행 중에는 키보드 입력이 숨겨지고 시트 화면 조작이 잠긴다).
3. **주행 2시간** — JARI가 먼저: "2시간째 운전 중이에요. 허리 지지대 위치를 바꿨어요. 다음 휴게소에서 잠깐 쉬어 가세요."
4. **주행 중 졸음** — "너무 졸려" → 운전석은 눕히지 않고 창문 20% + 통풍 3단, 휴게소 안내.
5. **배터리 20%** — JARI가 먼저 알림 → "충전소 찾아줘" → 빈 충전기가 있는 가장 가까운 충전소로 길안내.
6. **충전 시작(정차)** — 자동으로 휴식 자세. 충전이 끝나면 운전 자세로 복귀하고, 화면에 충전량·요금을 보여 준다.
7. **도착** — "트렁크 열어줘". 장거리 후 정차하면 JARI가 "수고하셨어요" 인사와 함께 휴식 자세를 제안.

## 5. 개발 계획

| SDK | 사용 API / 권한 | 용도 |
|---|---|---|
| Vehicle 2.3.2 | `Seat.moveSeat{ForeAft,BackrestAngle,Height,LumbarForeAft}`, `setHvacSeat{Temperature,Ventilation}`, `getCurrentSeatOccupancy`, `registerSeat*Position` / `CAR_SEATS`, `CONTROL_CAR_SEATS` | 자세·열선·통풍 제어, 탑승 좌석 판별, 실제 위치 추종 |
| Vehicle 2.3.2 | `Window.setWindowPosition`, `checkWindowPositionCapabilities` / `CAR_WINDOWS`, `CONTROL_CAR_WINDOWS` | 창문·선루프, 환기 |
| Vehicle 2.3.2 | `Gear.registerGearSelection` / `CAR_DRIVE` | 주행·정차 판별(안전 가드), 연속 운전 시간 측정 |
| Vehicle 2.3.2 | `EvBattery.registerEvBatteryStateOfCharge`, `setEvChargeSwitch`, `setEvChargePercentLimit`, `setEvChargePortOpen` / `CAR_ENERGY`, `CONTROL_CAR_ENERGY` | 배터리 알림, 충전 세션, 충전 중 휴식 |
| Vehicle 2.3.2 | `Door.setDoorPosition(REAR / HOOD)`, `registerDoorPosition` / `CAR_DOORS`, `CONTROL_CAR_DOORS` | 트렁크·프렁크 |
| NaviHelper 3.0.5 | `requestRoute(RouteInfo)` / `NAVI_ROUTE_SEARCH` | 충전소 길안내 |
| SpeechToText 3.3.1 | `request / stop`, ON_DEVICE / `STT_SERVICE` | 음성 입력 |
| TextToSpeech 3.3.1 | `speak`, ON_DEVICE / `TTS_SERVICE` | 음성 응답, 먼저 말 걸기 |
| FusedLocation | (2차 PT까지) 현재 위치 기준 충전소 거리 계산 | 현재는 미사용 |

- **구현 범위 — 1차 제출 시점(구현 완료):** 위 표의 FusedLocation을 제외한 전 기능. Pleos Connect 에뮬레이터 v2.1.0에서 동작, 에이전트 규칙·안전 가드 단위 테스트 20개 통과, release APK 제공. Pleos 음성·내비 서비스가 없는 환경에서는 안드로이드 기본 음성인식·TTS와 앱 내 길안내 시뮬레이션으로 대체한다.
  - 한계(숨기지 않고 밝힘): 발화 해석은 온디바이스 규칙 기반이다. 충전소 정보는 데모용 고정 데이터다. 에뮬레이터가 시트 모터를 시뮬레이션하지 않아 시트는 시간 기반으로 구동하며, 실차에서는 `registerSeat*Position` 실제 위치를 따르도록 구현돼 있다.
- **2차 PT 시점:** ① 발화 해석을 LLM으로 교체(규칙 기반은 오프라인 폴백으로 유지) ② 공공 충전소 API + FusedLocation으로 실시간 충전소 ③ 탑승자별 선호 자세 프로필 저장.
- **운전자 주의분산 대응:** 주행 중(기어 ≠ P) 키보드 입력 숨김·시트 화면 조작 잠금·음성만 허용(Pleos 주행 규제 `NO_KEYBOARD`·`NO_SETUP`), 먼저 말 걸기는 배터리·도착 알림이 주행당 1회, 장거리 알림이 2시간 간격이다. 글자 크기는 Pleos 디자인 가이드의 물리 높이 기준(주요 정보 5mm, 보조 3mm)을 실차 화면에서 아직 점검하지 못했다. 화면 수동 조작도 음성과 같은 안전 가드를 거친다.

## 6. 기대효과 및 발전 가능성

> 사실과 가정을 구분해 적는다. 가정은 2차 PT 전까지 아래 검증 계획으로 확인한다.

**타깃 고객**
- 1차 타깃: Pleos Connect 차량 중 **자동 자세 보조 기능(에르고 모션 시트)이 없는 트림**을 타고, 한 번에 2시간 이상 운전하는 일이 잦은 차주. 대표 차종은 아반떼(CN8).
- 이들을 고른 이유: 그랜저 등 상위 차종은 주행 1시간 뒤 자동으로 작동하는 순정 자세 보조가 있지만, 이 타깃에게는 같은 역할을 하는 기능이 없다 **[확인: 아반떼 트림별 요추 지지 사양]**.
- 2차 타깃: 뒷좌석에 아이·부모님을 자주 태우는 가족 운전자(동승자가 말로 자기 자리를 조절).

**시장 규모와 예상 MAU**

| 단계 | 값 | 근거 |
|---|---|---|
| 국내 Pleos Connect 탑재 차종 판매 | 월 약 1만 4천 대 → 연 약 17만 대 | 사실: 그랜저 8,898·6,989대, 아반떼 7,305·5,730대(2026년 9·10월, 현대차 발표). 두 달 평균을 연으로 환산한 것은 가정 |
| JARI가 작동 가능한 차량 | 그중 50% → 약 8만 5천 대 | 가정: 전동 운전석·열선/통풍 장착 비율. 아반떼는 전동 운전석이 선택 패키지라 실제 비율 확인 필요 |
| 앱 설치 | 5~10% → 약 4천~8천 대 | 가정: 실측 근거 없음. App Market 등록 앱이 18개로 적다는 점만 사실 |
| 월 활성(MAU) | 설치의 50% → **약 2천~4천 명** | 가정: 2주 사용 실험으로 대체 예정 |

- 전제 조건: 차량 제어 권한은 App Market과 사전 협의·승인을 받아야 선언할 수 있다(Pleos 심사 가이드). 승인되지 않으면 위 숫자는 성립하지 않는다.
- 3년 누적(같은 판매 수준, 차종 확대 없음 가정) 약 50만 대 기준으로는 MAU 약 6천~1만 3천 명.

**Retention (목표치이며 예측이 아님)**
- 목표: 1개월 40%, 3개월 25%. 실측값이 없어 2주 사용 실험 결과로 교체한다.
- 유지될 것으로 보는 이유: 앱을 열지 않아도 장거리 주행마다 "먼저 챙기기"가 작동한다. 반대로 장거리 운전이 드문 사용자는 이탈할 것으로 본다.

**비즈니스 모델 (가설 — 가격·전환율은 전부 실험 전 값)**

| 항목 | 내용 |
|---|---|
| 고객 | 사용자와 구매자가 같다: 자동 자세 보조가 없는 트림의 장거리 운전 차주 |
| 가치 제안 | 시트를 직접 조작하지 않아도 장거리 주행 중 자세가 바뀌고, 몸 상태 한마디로 시트·창문이 조합된다 |
| 무료 (설치·사용 확보용) | 증상 기반 음성 조합, 복합 문장, 주행 안전 가드, 트렁크·창문 제어 — 순정 음성비서와 겹치는 영역이라 돈을 받지 않는다 |
| 유료 "JARI 케어" | 먼저 챙기기(장거리 자세 변화·휴식 권유), 충전 중 휴식 루틴, 탑승자별 선호 자세 저장(개발 계획) — 순정에 없거나 상위 트림 옵션에만 있는 영역 |
| 과금 단위 | 차량 1대당. 실험 가격 두 가지: 1회 19,000원 / 월 1,900원 |

**문제 정의의 최소 변경:** 타깃을 "모든 운전자의 컨디션 케어"에서 **"순정 자동 자세 기능이 없는 트림의 장거리 운전자"** 로 좁힌다. 기능 추가 없이 현재 구현 그대로 적용된다.

### 부록 5. 사업성 검증 계획 (2차 PT 전, 소규모)

**사용자(대상 트림 차주 10명 내외)에게 — 의견이 아니라 지난 행동을 묻는다**

- 차에 있는 시트 메모리·음성비서·자세 보조 기능을 알고 있는가, 마지막으로 쓴 게 언제인가?
- 시트·편의 옵션에 돈을 낸 적이 있는가? 얼마였고 왜 골랐는가?

**구매자 후보(렌터카·법인 차량 담당 2~3곳, 충전 사업자 1~2곳)에게 — ③④를 다시 볼지 판단용**
- 운전자 휴식·피로 문제로 지난 1년간 실제로 쓴 비용이나 사고가 있었는가? 지금은 어떤 도구로 관리하는가?
- 차량당 월 요금을 내는 서비스가 무엇이고, 예산 결정은 누가 하는가?
- (충전) 유입 고객에 대해 수수료를 내는 채널이 지금 있는가?

**기존 방식과 비교할 지표**
- 같은 과제(예: 허리 지지대 올리고 열선 2단)를 순정 메뉴 / 순정 음성비서 / JARI로 수행한 시간과 화면을 본 횟수
- "먼저 챙기기" 권고를 끄지 않고 유지한 비율
- 2주 뒤에도 주 1회 이상 스스로 쓴 사람의 비율

**유료 실증 의향 확인**
- "좋다"는 반응은 세지 않는다. 가격을 제시하고 **환불 가능한 예약금 결제**까지 한 사람만 센다.
- 사업자에게는 견적서를 보내 **유료 실증에 서면으로 동의**하는지만 센다.

**판단 기준 (사전에 정함)**
- 계속: 차주 10명 중 3명 이상이 예약금을 결제하고, 2주 뒤 절반 이상이 주 1회 이상 사용
- 방향 전환: 결제 0~1명이면 ①을 접고, 사업자 인터뷰에서 실제 비용 문제가 확인된 모델로 옮긴다
- 중단 검토: 양산 차량에서 서드파티 시트 제어가 허용되지 않으면 사업 전제가 사라진다

### 부록 6. 확대 계획 (검증 통과를 전제로 한 계획)

- 1단계: 대상 트림 1개에서 실차 검증과 유료 실험
- 2단계: 지원 차종·트림 확대(차종별 보정), 탑승자별 선호 자세 저장
- 3단계: Pleos Connect 전기차가 국내에 나오면 충전 중 휴식을 묶어 ④를 재검토, Pleos Fleet API 연동으로 ③을 재검토
